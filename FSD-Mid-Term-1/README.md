# Library Management System

## Introduction
This is a simple Library Management System developed using Node.js and Express.js. It is used to perform basic operations related to books in a library.

## Features
- Add a new book
- View all books
- View book details using ID
- Update book details
- Delete a book
- Issue and Search a book

## Technologies Used
- Node.js
- Express.js
- JavaScript

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Install Express:

   npm install express

4. Run the server:

   node server.js

5. Open the API using:

   http://localhost:3000

## Data Storage
Book details are stored in a JavaScript array. No database is used.

## API Testing
I used Postman to test the API requests like GET, POST, PUT and DELETE.
